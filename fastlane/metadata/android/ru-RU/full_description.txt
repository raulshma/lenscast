LensCast превращает ваше Android-устройство в сетевую камеру с профессиональным управлением, удалённым веб-доступом, интервальной съёмкой и записью по расписанию.

Камера
• Живой предпросмотр с профессиональной панелью быстрых настроек
• Ручное управление: компенсация экспозиции, ISO, баланс белого, режим фокуса, зум
• Поддержка нескольких объективов (ультраширокоугольный, широкоугольный, телевик) с переключением на лету
• HDR, стабилизация изображения, разрешение до 4K, частота кадров 15–60 fps
• Съёмка фото и запись видео
• Режим ночного видения / ИК, сюжетные режимы, ручная дистанция фокуса, цветовая температура

Прямая трансляция
• Потоковое MJPEG-видео в реальном времени в любой браузер той же сети
• Воспроизведение с низкой задержкой в браузере (WebCodecs через WebSocket) с автоматическим переходом на MJPEG и HLS
• RTSP-трансляция со звуком AAC и видео H.264/H.265 в 480p/720p/1080p для VLC, OBS и видеорегистраторов
• Служба устройства ONVIF Profile S (по умолчанию выключена), чтобы NVR вроде Home Assistant могли находить камеру
• Режим HTTPS с самоподписанным сертификатом на устройстве

Веб-панель
• Просмотр живого потока, обзор и загрузка фото и записей
• Полное удалённое управление настройками камеры и трансляции
• Необязательная аутентификация по паролю

Автоматизация
• Фильтр распознавания объектов (необязательно): открытая модель EfficientDet-Lite0 — Apache-2.0, загружаемая по требованию с фиксированным SHA-256 с официального хостинга TensorFlow — запускает MQTT-уведомления или запись при появлении настроенных объектов
• Интервальная съёмка и запись по расписанию или непрерывная
• Фильтр звуковых событий (необязательно): открытая модель YAMNet — Apache-2.0, также загружаемая по требованию с фиксированным SHA-256 — запускает уведомления или запись при обнаружении настроенных звуков
• Тихие часы для уведомлений

Опциональные сетевые сервисы (все выключены по умолчанию; каждый работает только после включения и настройки)
• Резервное копирование в Telegram: автоматически загружает новые снимки и записи в выбранный вами чат Telegram (api.telegram.org)
• Web Push-уведомления: доставляет зашифрованные оповещения о событиях через push-сервис производителя вашего браузера (например, FCM от Google или autopush от Mozilla)
• Загрузка моделей: описанные выше опциональные модели распознавания загружаются по требованию с официального хостинга TensorFlow в облачном хранилище Google
• STUN-сервер для WebRTC-стриминга (публикация WHIP / просмотр WHEP): по умолчанию пуст, поэтому стриминг остаётся в локальной сети без обращения к сторонним серверам

Без рекламы, без слежки, без облака по умолчанию. Вся обработка остаётся на устройстве; веб-панель обслуживается встроенным HTTP-сервером в вашей локальной сети.

Примечание: сборка F-Droid распространяется без встроенного самообновления; обновления приходят из F-Droid.
